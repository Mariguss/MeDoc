## Приложение медицинского кооператива.
Приложение использует для работы коллектив врачей. 

В базу данных должны быть занесены имя, пол, дата рождения и домашний адрес каждого их пациента. 
(admin)

Всякий раз, когда врач осматривает больного, явившегося к нему на прием, или сам приходит к нему на дом, он записывает дату и место, где проводится осмотр, симптомы, диагноз и предписания больному, проставляет имя пациента, а также свое имя. 
(doctor)

Если врач прописывает больному какое-либо лекарство(admin), в базу заносится название лекарства, способ его приема, словесное описание предполагаемого действия и возможных побочных эффектов. (doctor)

Написать приложение, поддерживающее следующий функционал (admin):
1) по заданной дате определить количество вызовов в этот день; (inspections)
2) позволяют определить количество больных, заболевших данной
болезнью; (disease)
3) по заданному лекарству определить его побочный эффект порядке; (medicine)
4) предоставить возможность добавления нового лекарства с описанием его свойств. (medicine)
