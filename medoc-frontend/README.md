# MeDoc — фронтенд

Статический фронтенд без сборки (HTML + CSS + JS-модули) и маленький сервер `serve.py`
(стандартная библиотека Python), который раздаёт страницы и пересылает `/api/...` на бэкенд.

## Запуск

1. Запустите бэкенд (из папки MeDoc), по умолчанию он слушает http://127.0.0.5:8005:

       uv run python main.py

2. В папке `medoc-frontend`:

       python3 serve.py

3. Откройте http://127.0.0.1:5173 и войдите логином и паролем сотрудника.

Другой адрес бэкенда или порт:

    python3 serve.py --backend http://127.0.0.1:8000 --port 5173

## Что умеет
- Админ: сводка (вызовы по дате, больные по болезням, побочные эффекты лекарства),
  пациенты, лекарства, болезни, сотрудники, запись на приём.
- Врач: сводка, справочники (чтение), осмотры с диагнозом и назначениями.

## Структура
    index.html          страница-оболочка
    serve.py            раздача файлов + прокси /api -> бэкенд
    css/styles.css      оформление
    js/api.js           запросы к API, вход, обновление токена
    js/ui.js            формы, окна, уведомления
    js/crud.js          универсальная таблица-справочник
    js/pages/*.js       страницы
